# tora mark



tora markは、『Pokémon Champions』の対戦録画を解析し、ターン開始地点へ簡単に移動できるWindows向けの無料動画解析・再生ツールです。

録画された動画から各ターンの開始位置や選出画面を自動検出し、一覧として表示します。

一覧から目的の場面へ移動できるほか、検出位置の手動調整やTurnごとのメモにも対応しています。

対戦の研究や振り返り、解説などにご活用ください。

※ただし、自動解析の都合ターン開始位置を正確に読み取らない場合があります。
　必要な場合はユーザーにて手動で開始地点を追加ください。

tora markは非公式の個人制作ツールです。株式会社ポケモン、任天堂株式会社およびその他の関連企業とは関係ありません。




## 動作に必要なソフトウェア

tora markを使用するには、以下の2つのソフトウェアが必要です。

**1. Microsoft Visual C++ Redistributable（VC++ランタイム）**

アプリの動作に必要なMicrosoft公式の実行環境です。

以下のリンクから **x64版** をダウンロードし、インストールしてください。

- [Microsoft公式ダウンロード（x64版）](https://aka.ms/vc14/vc_redist.x64.exe)

**2. VLC media player**

tora markで動画を再生するために必要なソフトウェアです。

以下の公式サイトから **Windows 64bit版のVLC media player** をダウンロードし、インストールしてください。

- [VLC media player公式サイト](https://www.videolan.org/vlc/)

**インストール後は、tora markを起動してください。**

※すでにインストールされている場合、通常は再インストールする必要はありません。

※VLCが自動認識されない場合は、アプリの案内に従って `libvlc.dll` があるフォルダを指定してください。

※Pythonを別途インストールする必要はありません。





## 各ボタン・操作の説明

### 動画の読み込みと解析

| ボタン・操作 | 説明 |
|---|---|
| 動画を開く | 解析・再生したい動画を選択します。 |
| 解析 | 開いている動画を解析し、ターン開始位置や選出画面を自動検出します。 |
| 解析範囲 | 動画の中から解析対象とする範囲を指定します。全画面や保存済みの範囲を選ぶこともできます。 |
| 表示切替（▣ / □） | 解析範囲を拡大した表示と、動画全体の表示を切り替えます。 |

### 動画の再生操作

| ボタン・操作 | 説明 |
|---|---|
| 再生・一時停止 | 動画の再生と一時停止を切り替えます。 |
| 5秒戻る・進む | 動画の再生位置を5秒移動します。 |
| 10秒戻る・進む | 動画の再生位置を10秒移動します。 |
| 前・次のTurn | 前後のターン開始位置へ移動します。 |
| シークバー | 動画内の好きな時間へ移動できます。 |
| 音量・ミュート | 動画の音量調整や消音を行います。 |

### Turn一覧と手動編集

| ボタン・操作 | 説明 |
|---|---|
| Turn一覧 | 検出されたターンを選択すると、その開始位置へ移動します。 |
| 追加 | 現在の再生位置に新しいターンを追加します。 |
| 現在位置に修正 | 選択中のターンの開始位置を、現在の再生位置へ変更します。 |
| 削除 | 選択中のターンを一覧から削除します。 |
| メモ | 各ターンにメモを追加・編集できます。 |

手動で追加・修正したターンは保存され、再解析を行っても基本的に維持されます。

### その他の機能

| ボタン・操作 | 説明 |
|---|---|
| 選出画面一覧 | 自動検出した選出画面を確認できます。 |
| 設定 | テーマカラー、背景画像、ガラス効果などを変更できます。 |
| 右側パネルの開閉 | Turn一覧や操作パネルを折りたたみ、動画の表示領域を広げられます。 |

※自動検出した位置が実際のターン開始地点と異なる場合は、手動編集機能で調整してください。



アプリのEXEは「とら」名義の自己署名証明書で署名されていますが、Windowsが信頼する認証局の署名ではありません。起動時に警告が表示される可能性があります。Release掲載のSHA256を参照してファイルの同一性を確認できます。
